# smart-factory-predictive-maintenance

AI4I 2020 제조 데이터를 활용한 스마트팩토리 설비 고장 예측 및 데이터 분석 (6조)

## EDA 데이터 조작 보고서

분석 범위는 컬럼 추출, 기초통계, 전체 목록 저장, 그룹 연산, 오름차순·내림차순 정렬이다.

### 데이터 개요

| 구분 | 결과 |
|---|---:|
| 전체 행 | 10,000 |
| 전체 컬럼 | 14 |
| 전체 결측치 | 0 |
| 정상 비율 | 96.61% |
| 고장 비율 | 3.39% |

### 분석 대상 컬럼

- `Air temperature [K]`
- `Process temperature [K]`
- `Rotational speed [rpm]`
- `Torque [Nm]`
- `Tool wear [min]`

`UDI`, `Product ID`는 식별 컬럼이므로 제외했다. `TWF`, `HDF`, `PWF`, `OSF`, `RNF`는 고장 결과 정보로 데이터 누수가 발생할 수 있어 모델 입력 대상에서 제외한다.

### 제조설비 관점 해석

- 모든 컬럼의 결측치가 0개이므로 이번 단계에서는 결측치 처리로 인한 표본 손실이 없다.
- 고장 데이터는 339건(3.39%)으로 클래스 불균형이 크다. 이후 모델 평가에서는 Accuracy보다 Precision, Recall, F1-score, AUPRC를 우선 확인해야 한다.
- 고장 집단의 평균 토크는 50.168 Nm로 정상 집단의 39.630 Nm보다 높다.
- 고장 집단의 평균 공구 마모는 143.782분으로 정상 집단의 106.694분보다 높다.
- 그룹 평균은 집단의 전반적인 차이를 보여주지만 개별 고장의 원인을 직접 증명하지는 않는다.
- 공구 마모 정렬 결과는 마모가 적거나 큰 관측값을 빠르게 점검하기 위한 목록이며 고장 판정 기준 자체는 아니다.
